# Проверка проекта

Проверки выполнены 24–25 октября 2026 года.

## Автоматические проверки

Окружение: Windows, Python 3.13.7. Версии зависимостей закреплены в `requirements.lock`.

| Проверка | Результат |
|---|---|
| pytest | 84 теста пройдены |
| Покрытие прикладного кода | 98.75%: 317 из 321 исполняемой строки, без `app/generated` |
| Ruff lint и format | Пройдены |
| Генерация моделей `--check` | Модели совпадают с OpenAPI |
| `pip check` | Конфликтов зависимостей нет |
| Проверка OpenAPI | Спецификация валидна, маршруты и ответы соответствуют контракту |
| HTTP через отдельный Uvicorn | Health, POST, GET, PUT и ошибки 400/404/409 проверены |

Тесты используют временные SQLite-файлы. Проверяются полная замена полей при PUT,
регистронезависимый MD5, восемь одновременных попыток создания одной записи,
сохранение после перезапуска, миграция, ограничения данных, авторизация, rate limit,
размер тела запроса и отсутствие внутренних сведений в ответах об ошибках.

Повторить проверки из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest --cov=app --cov-report=term-missing --cov-fail-under=90
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
.\.venv\Scripts\python.exe scripts/generate_models.py --check
.\.venv\Scripts\python.exe -m pip check
```

## Проверка Docker и HTTPS

Окружение: Ubuntu 24.04 / WSL 2, Docker Engine 29.9.2, Docker Compose 5.6.1,
Caddy 2.11.7. Базовые образы Python и Caddy закреплены по digest.

Проверены сборка образа, запуск от UID 10001, HTTP-запросы из Windows и сохранение
SQLite после пересоздания контейнера. HTTPS проверен с реальным TLS 1.3: доверенная
цепочка и имя сервера принимаются, неизвестный CA и неправильное имя отклоняются.
Данные и сертификаты сохраняются в volumes после `down` и повторного `up`.
Внешний доступ в HTTPS-конфигурации ограничен `127.0.0.1:8443`; HTTP-порт API
не публикуется.

Для проверки используется отдельный Compose-проект и временные записи. Скрипт
`scripts/check_deployment.py` поддерживает сохранение MD5 созданной записи в файл
и её повторное чтение после пересоздания контейнеров. Приватные ключи и рабочая
база не нужны для передачи исходников.

Полный сценарий включён в `.github/workflows/ci.yml`. Команды выполнены локально;
удалённый запуск GitHub Actions не выполнялся.

Инструкция развёртывания: [deployment.md](deployment.md).
